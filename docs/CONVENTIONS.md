# MR.PERK Development Conventions

## JavaScript

- camelCase
- One responsibility per file
- One public feature per renderer

## CSS

- kebab-case
- One component per file
- Reusable first

## HTML

- Semantic
- Accessible
- Minimal

## General

- Never duplicate code.
- Prefer configuration over hardcoding.
- Build reusable systems before specific pages.
